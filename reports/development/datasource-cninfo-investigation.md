# 巨潮资讯网数据源调查：供应链关系能不能拿到？

> 调查时间：2026-11-13 20:45–21:10 · 调查方：`architect`
> 结论：**部分能拿到，但覆盖不了全部产业链。** 年报里的客户/供应商是匿名的，只有关联交易公告点名。
> 本文所有结论都有实测记录，日志见 `reports/testing/2026-11-13-cninfo-investigation.log`。

---

## 一、结论先说

| 数据路径 | 能拿到什么 | 能建边吗 |
|---|---|---|
| 巨潮公告列表 API | 标题、日期、PDF 直链、分类 | — |
| **年报「前五名客户/供应商」** | 金额、占营收/采购比例、集中度 | ❌ **名称匿名**（客户 A/B/C/D/E） |
| **年报「关联交易」汇总表** | 部分具名（控股股东、科研院所） | 🟡 少数具名，多数写「公司联营企业」 |
| **年报「重大合同」** | — | ❌ 多数标「不适用」 |
| **关联交易公告（单条）** | **具名交易对方 + 金额 + 期限 + 关系** | ✅ **可以，A 级证据** |
| 重大合同/中标公告 | 视公司而定 | 🟡 光模块类基本没有（保密条款） |

**一句话**：公开数据能建的是**关联方**之间的边，不是商业客户/供应商的边。

### 2.4 关联交易公告：这条能走通

太极实业 600667：

```
关于控股子公司海太半导体拟与SK海力士签署《第四期后工序服务合同》暨关联交易的公告
2025-06-19 · http://static.cninfo.com.cn/finalpage/2025-06-19/1223910508.PDF

正文：
  由海太半导体向SK海力士提供半导体后工序服务。
  未来5年（2025年7月1日至2030年6月30日）继续以"全部成本+约定收益"的盈利模式
  向SK海力士提供半导体后工序服务。
  SK海力士为公司子公司海太半导体第二大股东（持股45%），是公司关联人。
  公司持有海太半导体55%股权。
```

**双方具名、金额/定价模式、起止日期、股权关系，全都有。这是 A 级证据。**

### 2.5 为什么光模块公司拿不到

对中际旭创、新易盛搜「签订」「中标」：

```
300308 searchkey=签订 → 8 条，全是「募集资金三方监管协议」
300308 searchkey=中标 → 0 条
300502 searchkey=签订 → 2 条，同上
300502 searchkey=中标 → 0 条
```

To-B 供应链合同通常含保密条款，客户名不披露。**这不是采集能力问题，是信息本身不公开。**

## 四、覆盖率的现实估计

| 关系类型 | 公开数据可得性 | 说明 |
|---|---|---|
| 母子公司 / 控股 | 高 | 年报「合并范围」+ 关联交易，基本全覆盖 |
| 参股 / 合营 | 高 | 同上 |
| 关联方采购/销售（具名） | 中 | 只有披露了名字的才能建，很多写「联营企业」 |
| 商业客户（具名） | **低** | 年报匿名，合同多不披露 |
| 商业供应商（具名） | **低** | 同上 |
| 产业链上下游（推断） | 中 | 只能靠行业知识推断，属 `inferred`，不得 verified |

**所以「查某公司的上下游」这个功能，在公开数据下只能覆盖关联方那一小块。**

## 五、三条可选路线（需要你选）

### 路线 A：只做能拿到的（推荐起步）
- 采集「关联交易 / 日常关联交易 / 重大合同」公告 → 具名边，A 级证据
- 年报只抽「前五名集中度」作为公司风险指标（`entity.attributes.customer_concentration`），**不建边**
- 预期覆盖：50 家公司里可能有 15–25 条真实具名边（取决于披露）
- 成本：1 个采集器 + 1 个抽取器，属 P2
- 好处：全部可核验，零编造

### 路线 B：接付费供应链数据
- 企查查 / 天眼查 的「供应商/客户」图谱，或 Wind / iFinD 的产业链数据
- 覆盖率高得多，但要钱，且数据本身的来源与时效需另做可信度评估
- 需要你决定是否付费

### 路线 C：用研报产业链图谱，进候选层
- 券商研报里的产业链图，人工整理成 `inferred` Claim
- 只能进候选层（`pending_review`），不自动 verified，需要人工核验
- 好处：覆盖面广；坏处：全是二手推断，价值取决于核验投入

---

## 六、我的建议

**先做路线 A**，理由：

1. 它是唯一能产出「可核验、零编造」边的路径，正好符合这个项目的定位
2. 能顺带把 P2 的采集器骨架搭起来（巨潮接口已实测可用）
3. 覆盖率低不是缺点——**知道自己不知道什么，比假装什么都知道有价值**

同时把「前五名客户集中度」作为独立指标存下来。它虽然不是边，但对判断「这家公司依赖单一大客户」很有用，而且数据是真实的。

**不建议**用路线 C 去凑数。研报图谱看着热闹，但每条都要人工核验，成本会失控，而且很容易把推断当成事实——这正是本项目要防的。
